## 已知边界与保留差异

1. 鸿蒙元服务胶囊、状态/导航区域由系统绘制，不能复制Android系统栏。当前保留36vp胶囊避让；因此同分辨率截图中的应用内容纵向位置不能直接按整屏零偏差比较。
2. 中文采用各系统CJK回退字体，Roboto原文件只能确保其覆盖字符一致；系统抗锯齿、字体padding、Canvas阴影栅格化也有平台差异。未声称全画面逐像素零差异。
3. 原版随机题目/布局不使用共享种子，两个平台截图图案位置可能不同；对照颜色、资源、控件和几何规则，不把不同随机题误算为渲染差异。
4. 当前Android Game10/13/14确有`CloseButton.STROKE_WIDTH=3`造成棋盘下移/高行裁切。已用原APK截图确认，视觉实现保留，不擅自重新居中。
5. 当前Android“多与少”原APK启动时因缺少`android.support.percent.PercentFrameLayout`崩溃，不能取得有效玩法截图。鸿蒙按源码XML及CardStack还原且保持可玩，没有复制此崩溃。证据在`aligned/game12-crash.log`。
6. 无金币流程删除价格/余额/购买按钮；无限暂停、舒尔特48即结算、严格恢复剩余时间、高关卡生成上限仍沿用鸿蒙单机需求。
7. 当前制品未签名，已经成功安装开发模拟器；真机和正式分发需用户签名。取消项目2MB预算不代表平台实际元服务分发规则取消，发布前仍需按当期规则核对。
