# 需求：闯关地图模式

## 背景

首页目前把 23 款训练以列表形式全部展示，玩家一打开就能看到所有内容，缺少探索感。本需求把首页改为类似开心消消乐的闯关地图：玩家沿地图逐关推进，新游戏随关卡逐步出现。

已确认的决策：

- 金币购买保留，作为"提前解锁"的捷径。
- 应用尚未上线，不需要迁移老用户数据。
- 首期做 3 个章节。

## 术语

- **关卡（Stage）**：地图上的一个节点，由一款游戏和三档星级目标组成。
- **首发关**：某款游戏第一次在地图上出现的关卡。
- **已发现**：玩家已到达某款游戏的首发关（该关已开放）。
- **可玩**：游戏已发现，或已用金币提前解锁。
- **本局成绩**：用来和星级目标比较的数值。舒尔特方格（id 23）取找到的数字个数，248（id 17）取得分，其余游戏取本局完成的等级数（`level - 1`，与现有 `trophy()` 的口径一致）。

## 需求

### R1 地图与章节

1. 首页第一个标签页为"闯关"，展示 3 个章节的关卡地图。地图按章节分段，每章有标题横幅。
2. 第 1 关始终开放。其余关卡在前一关至少获得 1 星后开放。
3. 每个节点显示状态：未开放、当前关（下一个待通关的关卡，需突出显示）、已通关（显示 0 到 3 颗星）。
4. 未开放的首发关不显示游戏缩略图和名称，统一显示为问号节点。
5. 进入"闯关"标签页时，地图自动滚动到当前关。

### R2 关卡流程

1. 点击已开放的关卡后，弹出关卡详情，显示游戏名称、三档星级目标和"开始"按钮。
2. 如果该游戏的教程未看过，开始前先进入教程，这与现有的 `selectGame` 行为一致。
3. 关卡局从第 1 级开始，不使用自适应起始等级。
4. 游戏中显示当前关卡目标和实时进度，例如"目标 5 级 · 已完成 3"。
5. 以下任一情况发生时，本局结束并进入关卡结算：
   - 生命用完；
   - 时间用完；
   - 达到 3 星目标；
   - 玩家在暂停菜单中选择结束本局。
6. 关卡模式下生命用完不弹出现有的失败对话框，而是直接进入关卡结算。

### R3 星级与结算

1. 结算按本局成绩对照三档目标给出 0 到 3 星。至少 1 星即为通关。
2. 每个关卡只保存历史最佳星级。
3. 每次刷新该关卡的最佳星级时，按新增的星数奖励金币，每颗星 10 金币。这个数值以常量形式定义，后续可调整。
4. 游戏过程中现有的金币奖励（`levelCoins`、`scoreCoins248`）照常发放。
5. 结算界面显示星级、本局成绩、新增金币，并提供以下按钮：
   - "下一关"：仅在通关且下一关存在时显示；
   - "重试"；
   - "返回地图"。
6. 本局结束后，游戏记录（最高等级、最近成绩等）照常写入，"成长"页的数据不受影响。

### R4 新游戏发现

1. 通关后，如果下一关是某款游戏的首发关，结算后展示"发现新训练"提示，内容包括缩略图、名称和分类。
2. 23 款游戏按设计文档中的顺序分布在 3 个章节中，每款游戏恰好有一个首发关。

### R5 自由训练

1. 增加"训练"标签页，复用现有的游戏列表，供玩家单独练习可玩的游戏。练习使用现有的无尽模式规则。
2. 未发现且未购买的游戏显示为问号卡片，卡片上只显示分类和"第 X 章解锁"。
3. 点击问号卡片时弹出解锁对话框。对话框显示游戏名称和价格，玩家可以用金币提前解锁。
4. 已购买但尚未在地图上发现的游戏可以在"训练"页游玩；地图上的问号节点不受影响。
5. "成长"页的练习入口遵循同样的可玩规则。

### R6 解锁规则

1. 一款游戏只要已发现或已购买，就是可玩的。所有 23 款游戏都适用此规则，不再有默认开放的游戏。
2. 原来就收费的 10 款游戏保持现有价格。原来免费的 13 款游戏的提前解锁价格统一为 100 金币。
3. 已开放的关卡可以直接游玩，不需要购买。

### R7 存档

1. 存档版本升为 3，新增每个关卡的最佳星级。
2. 读取到版本 2 的存档时直接补全为版本 3，不报错。这只是为了避免开发测试机上出现"读取失败"，不属于正式的迁移方案。
3. 关卡星级数据同样要通过严格校验：长度不能超过关卡总数，每项必须是 0 到 3 的整数。

## 不在本期范围

- 体力或生命值限制游玩次数。
- 每关单独设定起始等级或专门的谜题参数。
- 章节星数门槛、每日挑战、关卡内道具。
