# Memory Games · HarmonyOS 元服务复刻

Android 客户端 `android_memory-game-reborn` 的 HarmonyOS（ArkTS / ArkUI）单机元服务复刻。
只参考本仓库中的 Android 客户端源码与资源，没有引入外部 Harmony 实现。

- 应用名：记忆训练大师
- bundleName：`com.razor.memory.brain.training.games`
- 包类型：`atomicService`（元服务，installationFree）
- 兼容版本：`5.1.1(19)`，编译 / 目标版本 `6.1.1(24)`

## 需求对应

| 需求              | 实现                                                          |
| --------------- | ----------------------------------------------------------- |
| 单机、无服务端         | 无网络权限、无 HTTP/WebSocket 代码，全部本地运行                            |
| 无底部菜单栏          | 首页直接是“冲刺”的 23 款游戏列表，无 BottomBar                             |
| 无金币、默认解锁        | 移除金币、解锁、购买、广告；全部游戏直接可玩                                      |
| 只参考 Android 客户端 | 玩法、关卡推进、文案、教程图、音效均来自本仓库 Android 源码/资源                       |
| 完整复刻游戏元素        | 新手教学、逐格动画、准备倒计时、暂停、失败、结算、音效、最高关卡、自适应起始关，保留用户达到的最高关卡、无暂停次数限制 |
| 视觉还原优先级（2026-10-18 修订） | 不考虑 2 MB 包体限制；以当前仓库 Android 客户端为唯一视觉基准，像素级还原布局、配色、字体、素材、棋盘、动画、弹窗与结算。图片使用原始高清资源，音效保留原始质量，不再为包体降采样或有损压缩。 |
