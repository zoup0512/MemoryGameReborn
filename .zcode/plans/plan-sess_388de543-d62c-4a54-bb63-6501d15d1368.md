# Android Dialog 统一改造

## 目标与边界
按照上轮评审，采用推荐的“克制浅色圆角卡片＋少量游戏化奖励元素”方向，覆盖当前实际使用的弹窗，不只修改示例退出框。保持现有 support-v7 26.1.0、Java 8、ButterKnife 架构，不迁移 AndroidX/Compose，不调整服务器、账号协议、金币价格、积分或存档规则。复杂账号流程本轮先优化现有可滚动表单，不另建整套导航页面。

当前工作区已干净，HEAD 为 `383246b`；此前数一数 release 反射崩溃修复已经提交，将完整保留。实施前再核对状态，在新工作分支开发，不提交或推送。

## 1. 公共弹窗基础
- 新增可跨包使用的 Dialog 样式与窗口工具，复用在线模块现有配色、字体缓存和卡片思想。
- 明确区分普通确认/输入卡片、游戏结果/奖励、答题覆盖层，不把所有窗口强行改成全屏。
- 统一不透明面板、约 20dp 圆角、24dp 内容内边距、48–52dp 最小操作区域，以及遮罩、按钮主次和错误状态。
- 为 support AlertDialog 配置显式主题，消除设备默认青绿色按钮和透底；提供可 `create()` 后挂业务监听的工厂，避免覆盖现有显示/关闭监听。
- 加深按钮和交互文字颜色，使普通文字对比度达到 4.5:1；不通过全局替换游戏棋盘色改变玩法视觉。
- 补充中英文文案，保留其他语言回退能力，避免无意义地重写旧资源。

## 2. 退出确认与在线弹窗
- 将基类的在线退出提示集中为可复用方法，删除 16 个子类重复提示实现，保留各子类离线返回中的计时器、保存和特殊分数处理。
- 所有入口根据练习/真实对战显示准确后果；按钮为“继续练习/对战”和“退出练习/对战”，取消不得停计时或认输。
- 在线金币不足提示取消“这里获取更多”的错误承诺；房码增加明确复制入口、准确到期说明；加入按钮改为“加入房间”。
- 保留难度选择整行点击和奖励信息，改善按钮语义、最小高度及大字体适配。
- 对局等待、间歇、最终结算保持 Activity 内状态板，不误改未使用的旧 Dialog 资源。

## 3. 传统游戏弹窗
- 暂停：继续为唯一主操作；教程、重玩、结束本局使用次级操作，保留声音开关和恢复回调。
- 失败/续关：去掉默认 5 秒自动退出，清楚显示重试本关的 30 金币成本、余额、次数/余额不足原因，提供主动重开和结束入口。保留现有扣费及重开流程，在执行时再次检查条件。
- 解锁：展示游戏名、价格与余额；余额不足不再出现确认空操作。
- 结束/挑战结果：先展示本局成绩、到达关卡或目标对比，再展示重玩、下一关、返回；推荐游戏下沉。只显示可从现有数据可靠取得的结果，不编造收益或纪录。
- 奖杯：保留庆祝元素与淡入淡出，补充可取得的达成信息，明确外点/返回与继续的行为。
- 训练邀请/帮助：以原生可本地化文字替代图片内英文说明；保留装饰图片；增加滚动和更易读正文，只有显式“不再提示”才保存永久拒绝。
- 同步实际生效的默认、API 与平板布局变体，保留必要 ID 和 ButterKnife 绑定契约；不删除未使用旧资产以免扩大范围。

## 4. 账号、诊断与评审发现的缺陷
- 账号表单统一面板、常驻字段标签、明确提交按钮；发送验证码按填写顺序放置；错误转为可理解的中文/英文提示，技术错误码留作次级诊断信息。保留异步禁用、敏感字段不保存和身份安全逻辑。
- 诊断上传分组呈现范围、内容、隐私和目的地，保留完整知情确认与快照清理语义；成功结果支持复制上传编号，避免自动上传。
- 修复 RateDialog 在布局加载前查找视图的空指针路径。
- 修复数一数正确选项不覆盖第四位置的问题，同时确保选项为有效正数、不重复；显示可发现的声音/暂停入口和文字化正确答案反馈，保留现有答题锁定、动画及 release 崩溃修复。
- 优先使用标准 Button；需保留复合可点击 View 时补齐按钮角色、焦点、描述和非颜色状态反馈。

## 5. 验证与交付
- 新增轻量回归检查，覆盖选项生成、资源/绑定契约、遗漏旧退出文案和布局变体；不把现有空单元测试任务当成有效覆盖。
- 使用 JDK 17 构建 debug APK，并运行现有诊断纯 Java 测试；执行适用的资源检查和 lint，区分历史告警与新增问题。
- 验证 release 编译/R8 与已有反射资源保护任务，避免仅 debug 通过。
- 优先使用已连接设备做安全的视觉验收，检查暂停、退出、输入、结果、奖励和账号表单；不确认扣费、不注销账号、不上传日志，不中断正在进行的真实对局。不卸载或清空应用；若安装测试包会覆盖不兼容签名或影响现有数据，则保留 APK 并说明设备验收限制。
- 覆盖可执行的窄屏、大字体、键盘和返回操作检查；无设备/无服务条件下无法验证的项目明确列出，不声称已通过。
- 最终给出改动范围、构建与测试结果、APK 路径及代表性截图，并说明剩余限制。
