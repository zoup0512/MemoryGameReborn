## 浏览器检查

仅启动 `127.0.0.1:18091` 临时验收实例，内存 H2 数据库；为缩短人工验收限制，实例管理限流显式设为 600/min。默认 60/min 及一次配置写入计数由自动化测试验证，不用该宽限实例代替默认限流验收。

- 错误 Token 返回 404 提示，输入内容清空；正确 Token 登录显示真实服务器与玩家数据。
- 运行概览显示两条认证连接和真实活动对局，明确为进程累计而非今日统计。
- 用户列表和详情展示两个本机测试用户及最近战绩，不补造服务端未返回的字段。
- 本机用户调币 `delta=5`，填写理由后先核对，再勾选二次确认并提交；按钮在提交期间禁用。回读真实余额，并在审计页找到 `USER_BALANCE ... delta=5 reason=本机网页验收补偿`。
- 验收期间对局自然发生断线结算，余额和 ELO 因业务结算同时变化。以审计中调币增量确认补偿，不把最终余额总变动全部归因于管理操作。
- 运维页读取维护 `enabled=false` 和 ROOT 日志级别 INFO，并展示真实事件和管理审计。
- 配置页展示毫秒/金币/胜场概率等准确单位；将入场费 30 改为 31，预览仅有该字段差异，取消后重新读取恢复 30，没有写入配置。
- 退出后恢复空登录页，业务内容与凭证输入清空。
- 1280×720 桌面和 390×844 窄屏检查：导航换行、配置表单由双列变单列，未发现文本重叠或外层横向溢出。

浏览器自动化的部分高层 click 定位发生工具超时；通过页面重新观察后的 DOM 节点/坐标及针对既有按钮的页面侧点击继续验证。功能结果以实际页面变化和服务器回读为准。对局强制结算、作废、维护写入、日志调整以及配置成功写入/部分失败等路径主要由 Java 和前端 mock 测试覆盖，不宣称这些写路径全部经过人工浏览器点击。
