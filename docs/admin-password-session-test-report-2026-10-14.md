## 部署注意

- 新增配置：`PK_ADMIN_PASSWORD_HASH`，bcrypt 哈希且没有默认值；工具最少 12 字符、最多 72 UTF-8 字节。
- 会话默认 28800 秒、最大 86400 秒；默认容量 1000，登录限流 5 次/分钟/IP。
- Cookie 为 host-only、HttpOnly、SameSite=Strict、Path=/api/admin；HTTPS 设置 Secure。本机 HTTP 例外要求 peer 与 Host 都为 loopback 且不带转发头。
- 服务端会话仅内存保存，重启失效；密码配置固定，不会自动轮换。刷新网页不会注销，退出会撤销。
- 生产 HTTPS 反代需网络隔离，保持 Host，清理伪造转发头，并显式开启可信转发选项；默认不信任转发头。
- 本次不新增数据库迁移。现有 V1..V6 未修改。
- 哈希工具真实交互输入没有在自动化执行器里模拟；无 Console 时安全拒绝。完整说明见 `admin-console.md`。
- PostgreSQL/Docker 测试和云端部署未执行；实际密码由管理员在自己的交互终端设置，开发验收凭证不是默认密码。
