## 真实本地协议验收

最终bootJar使用独立内存H2，仅监听127.0.0.1:18081，显式 `pk.auth.allow-http=true`、`pk.nickname.mode=disabled`。SMTP由验收脚本在loopback临时接收，不向真实邮箱投递；不调用第三方内容审核服务，不连接生产。

执行：

```bash
python docs/tools/nickname_smoke.py --base-url http://127.0.0.1:18081
python docs/tools/account_smoke.py --base-url http://127.0.0.1:18081
```

两脚本分别6项与9项检查全部通过：

- 安全默认昵称创建后持久恢复，不能借恢复请求覆盖。
- 非法长度、控制字符、零宽字符被拒绝。
- 审核缺配置返回503，原昵称、原头像与改名冷却均保持不变。
- 预设头像单独保存成功，头像URL被拒绝。
- 旧WS恢复不能改名；旧WS新建自定义昵称不能绕过审核。
- 邮箱验证码、游客原地升级、登录、refresh重放撤销、设备列表、全设备退出、密码重置、注销取消、退出关闭WS回归通过。

验收后已停止本轮启动的本地服务。
