# 统一亲友赛与取消固定人数上限

## 当前规则

- 新亲友房至少2人，全体非房主准备即可开始；没有固定最大人数。
- 一个亲友赛卡片提供创建、加入、战绩，不再分“双人”和“多人”。
- 创建进入3/5轮选择并确认；所有新房都走持续亲友大厅、六位房码、名次积分、免金币且不改排位分。
- 统一加入框兼容旧四位码；旧房仍走旧FRIEND协议和原经济/评分规则，提示明确，不能把新房免费规则套给旧房。
- 人数显示只展示当前人数，不再展示`/6`或其他最大人数。
- 亲友战绩页展示新积分赛并提供旧版双人亲友历史入口；旧历史在数据库先按FRIEND过滤再取最近20条，避免被近期排位/练习挤掉。

## 协议与存储

`party_state.capacity=0`表示没有固定产品人数限制。旧客户端仍有本地3–6人门槛，需更新才能使用统一界面；新客户端必须配套新服务端。

积分字段`points2`全链使用64位整数；V10将`pk_party_participant.points2`从INTEGER拓宽为BIGINT，不修改已发布V9。旧战绩值不改变。

有效`party_level`返回带rid的轻量`party_ack`；每房250ms dirty窗口合并得分广播（现100ms tick，实际250–350ms）。阶段变化、成员变化和sync即时给权威状态。客户端ack只清理命令关联，不修改房间快照或复活旧局。

没有固定人数上限不等于无限容量：全局房间总量、用户/IP限流、认证、单账号占用、发送队列和数据库积压背压继续保留。单份快照O(N)，发给全员的总网络量仍O(N²)/批；本次避免每关重复全量广播，没有声称任意规模已验证。
